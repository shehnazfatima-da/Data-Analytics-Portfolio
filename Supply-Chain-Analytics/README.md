# 📦 Supply Chain Analytics

## 📌 Overview

This project analyzes supply chain operations to improve efficiency, optimize inventory management, evaluate supplier performance, and monitor order fulfillment using SQL, Excel, Tableau, and Power BI.

---

## 🛠️ Tools & Technologies

- MySQL
- Microsoft Excel
- Power BI
- Tableau

---

## 📊 Skills Demonstrated

- Data Cleaning & Transformation
- SQL Query Writing
- ETL Process
- Dashboard Development
- KPI Reporting
- Data Visualization
- Business Intelligence

---

## 📈 Key KPIs

- Total Orders
- Inventory Turnover
- On-Time Delivery Rate
- Order Fulfillment Rate
- Shipping Performance
- Warehouse Efficiency
- Stock Availability

---

## 💡 Business Insights

- Identified bottlenecks affecting order fulfillment.
- Analyzed supplier performance to improve procurement decisions.
- Evaluated inventory trends to reduce stock shortages and overstocking.
- Monitored delivery performance to enhance customer satisfaction.
